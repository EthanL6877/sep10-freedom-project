In this unit, I learned about several foundational tools and concepts in coding, including HTML, CSS, Bootstrap, GitHub, and AVD. HTML was my introduction to coding, and while it is considered a basic starting point, I found it challenging because even small mistakes could cause big issues that were difficult to debug. CSS was a addition to HTML as it allowed me to style and decorate web pages, giving me creative freedom through colors, layouts, and even animations. I learned how to use GitHub to Git my work together as tools for collaboration and version control as it was how the basis to which coding can be used. To better explain what it is, GitHub acts as a central hub where repositories store code, images, and other files, while Git allows changes to be made locally and then pushed to the remote repository. I learned how to add and commit changes, as well as how to handle merge conflicts when multiple changes happen at once. Bootstrap made designing easier by providing pre-made components and a grid system using containers, rows, and columns, which helped me create responsive websites that adjust to different screen sizes like mobile devices, tablets, and computers without starting from scratch. In my tinkering, I used jQuery to include interactive behavior. To explain what jQuery is, jQuery is a JavaScript library designed to make it easier to select elements, handle events, and create effects without writing as much complex code as compared to the much more bulky version of JavaScript. By using jQuery, I was able to apply changes to text, buttons, and other elements. One feature I used was event handling, which lets you run code when a user clicks or interacts with text or images, making the page feel more user responsive. I also used animation functions like fadeOut, toggle, delay, and animate, mousedown, alert, which allowed elements to smoothly disappear or move, with other functions like Toggle and Delayallowing me to change how the elements will function, while alert gave a notification depending on a requirement; if no requirement was given, it was set at the start of the page. Another important part of how jQuery works is that it uses simple selectors, similar to CSS, to target specific elements on a page. This made it much easier for me to control exactly what I wanted to change without affecting the rest of the webpage, especially with the fact that jQuery still works with normal CSS and HTML, letting me expand my range of abilities or simplifying the code so it isn't so messy/hard to look at.
