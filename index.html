Context

In this unit, I learned about several foundational tools and concepts in coding, including HTML, CSS, Bootstrap, GitHub, and AVD. HTML was my introduction to coding, and while it is considered a basic starting point, I found it challenging because even small mistakes could cause big issues that were difficult to debug. CSS was a addition to HTML as it allowed me to style and decorate web pages, giving me creative freedom through colors, layouts, and even animations. I learned how to use GitHub to Git my work together as tools for collaboration and version control as it was how the basis to which coding can be used. To better explain what it is, GitHub acts as a central hub where repositories store code, images, and other files, while Git allows changes to be made locally and then pushed to the remote repository. I learned how to add and commit changes, as well as how to handle merge conflicts when multiple changes happen at once. Bootstrap made designing easier by providing pre-made components and a grid system using containers, rows, and columns, which helped me create responsive websites that adjust to different screen sizes like mobile devices, tablets, and computers without starting from scratch.
